# 🚀 QUICK START - Get Playing in 2 Minutes!

## ⚡ Fastest Way to Play Right Now

### On Your Computer:
1. Download all files from the `mobile-duck-kong` folder
2. Double-click `index.html`
3. Game opens in your browser!
4. Select a duck and play (use keyboard: arrows + space + shift)

### On Your Phone (Test Touch Controls):
1. Download all files
2. Put them in a folder on your phone
3. Open `index.html` in mobile browser
4. Touch controls appear at bottom of screen!

## 📱 Install as Real App (5 Minutes)

The EASIEST way is GitHub Pages (100% Free, No Coding):

### Step 1: Create GitHub Account
- Go to github.com
- Click "Sign up"
- Create free account

### Step 2: Upload Your Game
- Click the "+" icon (top right)
- Select "New repository"
- Name it: `duck-kong`
- Make it Public
- Click "Create repository"

### Step 3: Upload Files
- Click "uploading an existing file"
- Drag ALL files from mobile-duck-kong folder
- Click "Commit changes"

### Step 4: Enable GitHub Pages
- Go to Settings tab
- Click "Pages" in sidebar
- Under "Source", select "main" branch
- Click Save
- Wait 1-2 minutes

### Step 5: Get Your URL!
- URL appears: `https://yourusername.github.io/duck-kong`
- Copy and share this link!
- Open on your phone
- Tap "Add to Home Screen"
- DONE! 🎉

## 🎮 How to Play

**Desktop:**
- Arrow Keys = Move
- Space = Jump
- Shift = Special Ability
- ESC = Pause Menu

**Mobile:**
- Touch the on-screen buttons
- ← → = Move
- JUMP = Jump (double-tap for Mandarin's double jump!)
- ⚡ = Special Ability
- ⏸ = Pause (top-right corner)

## 🆘 Need Help?

**Game won't load?**
- Make sure ALL files are in same folder
- Try different browser (Chrome recommended)

**Can't install on phone?**
- Must be HTTPS (GitHub Pages is automatic HTTPS ✅)
- Or use `localhost` for testing

**Touch controls not showing?**
- Only appear on mobile devices
- Desktop uses keyboard only
